# GoSource collection storage repair

Sprint: #118; Story: #52; Story-ID: d564bada90bb

The complete collection gate exposed a host panic when indexing a represented
nil map. Nil slices had the same unchecked payload assertion. Repair these
reads and writes first, then preserve typed collection metadata through nested
calls and assignments. Keep the existing corpus gate running in full and retain
its failures. Original Go examples and comparators are unchanged.

The implementation carries positioned `make` size expressions through the AST,
including typed JSON, and evaluates collection builtin operands once in source
order. Reads used by native arguments no longer probe and then re-evaluate an
index. Map comma-ok declarations copy value elements while preserving reference
members. Structured assignment evaluates its index before its RHS and retains
nested collection metadata. Nil and malformed storage produce language errors
instead of an escaping host assertion panic. Native objects stored in aggregate
fields retain their authenticated session handles and concrete type identity;
no native program body or method body is generated by this change.

Verification includes nine authored programs and three hash-bound, unchanged Go
Tour programs in the Go SDK, interpreter, and a real source-free native artifact.
Controls cover side-effect order, single evaluation, nil storage, typed scalar
formatting, copy/alias behavior, map value copies and native time.Time fields.
Additional controls check invalid accesses remain contained, typed JSON preserves
make operands, and corrupting compatibility words does not alter lowering.
Run these under the race detector and run the existing classic collection,
builtin, readonly and struct tests plus TestRunnerRunConfirm.

The full tagged collection audit remains the acceptance diagnostic. This slice
does not claim exact native panic stack text, compiler-dependent optimized
initial append capacity, every local/anonymous type's bridge registration, or
all result-bearing builtin return paths. Those failures remain executable;
no case is removed or its comparison relaxed. Native object bridge codecs and
function return handling are separate cooperating changes.

Measured local results: the complete 26-row tagged audit executes without a
host panic: 18 PASS, 8 FAIL. Remaining rows are slice-literals, growth capacity,
named-element alias conversion, nil map write and nil slice index panic text,
spare-capacity local type registration, conversion passed to a call, and
map-of-slices entry registration. All remain in their original gate.
The focused interpreter/classic controls pass in 82.418s; the 12-program
three-mode controls and invalid-index controls pass with race instrumentation
in 122.261s. Dedicated AST/typed-JSON controls pass. TestRunnerRunConfirm against
native Bash 5.3.15 fails in 18.476s on fixture/environment differences including
continue diagnostics, formatting, HOME expansion and missing dynamic helpers;
this is not reported as shell conformance PASS.

The full gosource package passes in 61.291s and syntax/typedjson in 1.804s.
